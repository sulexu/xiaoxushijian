# 小煦拾简

> 拾寸简以记，沐小煦而行。

**一个安静的个人生活记录本。** 打卡、记账、物资、待办、日记、随笔、回忆书，
都在一个窗口里。数据存在你自己的电脑上，不上传、不注册、不联网也能用。

不想要弹窗提醒，不想让生活变成某个 App 的日活数据，不想云同步「会员专享」——
那就自己写一个。

  <a href="https://github.com/sulexu/xiaoxushijian/releases/latest">

## 它长什么样

- **七套配色** × 深浅两模式：素纸、米黄、青瓷、墨色、樱粉、蓝粉、藕荷
- **日记和随笔是古书竖排** —— 界格线、织纹、朱印，从右往左读，
  英文和数字也竖着排
- **两套自带书法字体**，设置里随手换：

  | | 风格 |
  |---|---|
  | **瘦金体** | 宋徽宗那种细瘦带尖锋，笔画如铁画银钩 |
  | **马善政行书** | 毛笔行书，笔画连贯流动 |

- **背景图**可以放一张自己的照片，调模糊、遮罩、卡片通透度

## 功能

| 模块 | 做什么 |
|---|---|
| **总览** | 一屏看完今天：结余、可动用资金、本月支出、今日梦境、待补货、待办、牛马时钟 |
| **账单** | 记账（收入/支出/团购/核销）、分类统计、月度图表、比上月涨太多会提醒你 |
| **打卡** | 日常打卡项、连续天数、心情记录 |
| **物资** | 药品 / 日用品 / 应急信息三张表，库存和过期提醒 |
| **待办** | 按类别、优先级、状态、关键词筛选；能一键加进电脑日历 |
| **日记** | 每日 / 每周 / 每月，古书竖排版式 |
| **随笔** | 随手写，竖排 |
| **回忆书** | 把过去的日记整理成问答，往回翻的时候有迹可循 |
| **牛马时钟** | 按小时工资算「今天已经赚了多少」，还有个能常驻桌面的小窗 |

**可选**：接自己的 DeepSeek Key，让 AI 帮你把随手记的一句话整理成日报、
识别药盒照片、或者就着日记问你几个问题。**不配 Key 就完全用不到这个功能，
也就不会有任何内容发出去。**

## 关于隐私

**你的数据在你自己电脑上。** 默认存在 `文档\小煦拾简\数据\`，
就是一个 SQLite 文件加一堆 Markdown，可以直接复制走、可以直接看。

- 不需要注册，不需要登录任何账号
- 没有云同步，没有遥测，没有「改进产品体验」
- 前端没有任何外部请求（没有 CDN、没有在线字体、没有统计脚本）
- **唯一会联网的地方是 AI 功能**，而且必须你自己填 Key 才生效；
  用它的时候，被整理的那段内容会发去 DeepSeek 处理

> 这个仓库里也**没有任何人的数据**。发布出去的安装包是个**空程序**，
> 第一次打开才在你电脑上建库。

## 安装

**方式一：安装包**（推荐）

去 **[Releases](https://github.com/sulexu/xiaoxushijian/releases/latest)** 下载
`xiaoxushijian-x.x.x-setup.exe`，双击，一路「下一步」。
装完桌面会有「小煦拾简」快捷方式。

> 安装包文件名是拼音，因为 GitHub 的附件名会把中文剥掉变成 `-2.5.1-.exe`。
> **程序名和快捷方式仍然是中文「小煦拾简」。**

**方式二：从源码跑**（不需要安装任何东西）

```bash
python server.py
```

然后浏览器打开 `http://127.0.0.1:8765`。

只需要 **Python 3**，**不用 pip install** —— 后端全部用标准库写的。

## 技术

给想看代码的人：

| 层 | 用了什么 |
|---|---|
| 后端 | **Python 3 标准库**（`http.server`）—— 零依赖 |
| 存储 | SQLite（`store.py`）+ Markdown 文件（`notes.py`） |
| 前端 | **原生 JS**，无框架、无构建（`core.js` + `app.js`） |
| 图表 | ECharts（本地文件） |
| 桌面壳 | Electron；打包 PyInstaller + electron-builder |
| 样式 | 手写 CSS，正在渐进迁移到 Tailwind + daisyUI |

**为什么不用框架**：这是个单人用的小工具，改完刷新就见效比什么都重要。
没有 node_modules、没有 webpack、没有「先跑一下 dev server 等热更新」。

```
server.py          后端全部路由
store.py           SQLite 存储层
notes.py           Markdown 笔记
export.py          导出
vision.py          看图录入

static/
  core.js          基础设施（主题、背景、字体、工具函数）
  app.js           所有页面
  style.css        样式
  fonts/           两套自带书法字体

electron/          桌面外壳
_build/server.spec PyInstaller 配置
```
