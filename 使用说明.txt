【小煦拾简 · 使用说明】（2.4.6）

一套本地系统，管你的日常数据：
  总览 / 账单 / 打卡 / 物资 / 待办 / 日记 / 随笔 / 回忆书 / 设置
  —— 能看、能改、能记。

━━━ 这份文档讲什么 ━━━

  只讲**功能怎么用**，一条一条列清楚。
  想快速上手看《新手说明》；想知道每个版本改了什么、修过什么问题、踩过什么坑，
  看《项目历程》；想改代码看《项目交接》。

━━━ 安装 ━━━

  双击「小煦拾简-2.4.5-安装版.exe」，可以自己选装到哪儿。

  **装完第一次打开，它会先找你的数据**，按这个顺序：
    ① 免安装版的摆法 —— 数据就在 exe 旁边（或往上三层）
    ② 上次用过的那个目录（程序记在 %APPDATA%\小煦拾简\数据位置.txt 里）
    ③ 「文档\个人信息统计」里如果已经有数据
    ④ 一个都没找到 → **弹一个框问你**：
       「选一个文件夹…」/「建一个空的」/「先退出」

  ⚠ 第 ④ 步是 2.4 改的。2.3.x 那会儿是「没找到就默默在『文档\小煦拾简』
  建一个空库」—— 对头一次用的人没问题，但你要是以前一直用免安装版、
  或者自己挪过文件夹，它就会给你一个**空库**：打开看到账单 0 条、物资 0 行，
  换了谁都会说「我数据没了」。而「数据在哪」这件事是**问得到的**，
  所以现在问了，多花三秒。（这也是那一次「数据没了」的修复。）

  **已经有一份数据想接着用？** 三种办法，任选一种：
    · 第一次打开那个框里点「选一个文件夹…」，直接指给它（最省事）；
    · 把装着数据的那整个「个人信息统计」文件夹（里面有 小煦拾简.db）
      放到安装目录**旁边**，它自己认；
    · 或者把数据的完整路径写进这个文件（只有一行）：
          %APPDATA%\小煦拾简\数据位置.txt

  卸载**不会删你的数据**（数据本来就在你自己的文件夹里，不在安装目录）。

其中「日记」和「回忆书」移植自开源项目 SpringNote（github.com/Radiant303/SpringNote），
日报/周报/月报存成 Markdown 文件而不是塞进数据库（原因见下文「日记」一节）。

⚙ 设置页：九个分区，见下文「设置页」一节。

━━━ 启动（免安装版 / 源码版，任选） ━━━

  ★ 免安装版（推荐，换电脑也不用装任何东西）
     整个「小煦拾简」文件夹拷到哪都能跑，里面自带 Python 和 Node 运行时。
     双击「小煦拾简.exe」→ 弹出独立窗口，任务栏有自己的图标；
     关闭窗口 = 停止系统（后端一起退出）。
     · 首次启动要解包，慢一点（十几秒），之后就快了。
     · 杀毒软件可能拦一下，选「允许运行 / 仍要运行」即可（程序没做签名）。

     数据放哪儿？程序自己按这个顺序找，**不用你操心**：
       ① 就在 exe 旁边（或往上三层）找到 `小煦拾简.db` → 直接用
       ② 上次用过的那个目录（程序记着）
       ③ 「文档\个人信息统计」里如果已经有数据 → 用那个
       ④ 都没有 → **弹一个框问你**（选一个文件夹 / 建一个空的 / 先退出），
          见上文「安装」一节
     ⚠ 想让它读你原来那套数据：在 ④ 那个框里点「选一个文件夹」直接指给它，
       或者把 `小煦拾简.db` 放到 exe 旁边，再启动就行。

  ① 源码版 · 桌面窗口（像微信一样）：
     双击「桌面版.bat」→ 打开独立的应用窗口
     底层是 Electron 壳 + Python 后端，界面和数据逻辑完全不变。
     依赖已装好；如果换了电脑，先在该目录跑一次 npm install 再启动。

  ② 源码版 · 浏览器：
     双击「启动.bat」（或命令行 python server.py）
     → 自动打开浏览器 http://127.0.0.1:8765，默认落在「总览」页
     → 关掉那个黑色命令行窗口 = 停止系统

  要求：免安装版什么都不用装；源码版需要 Windows + Python 3.8+ 和 openpyxl，
       桌面版额外需要 Node.js。
  如果浏览器没自动打开，手动访问 http://127.0.0.1:8765

━━━ 九个标签页 ━━━
🏠 总览（默认页）
   · 顶部横幅（hero）：今天日期星期 + 一排今日数字（今日核心完成度 / 本月完成率 /
     可动用资金 / 待补货数 / 今日支出；填了日薪还会多一格「牛马时钟」）
   · 七张卡片：结余、可动用资金、本月支出 vs 预算、今日梦境、待补货、
     待办未完成、牛马时钟。哪几张显示、谁排前面，在设置 → ✨ 个性化 里勾
     （牛马时钟要填了日薪才出现，没填就是没这回事，不摆个 0 在那儿）
   · **随手记**：横幅里那个输入框，想到什么写一句，Ctrl+Enter 提交。
     AI 会把它整理进「今天的日报」，不用管格式。
     旁边还有「用模板写」（2.3.6）—— 15 套模板挑一套照着填
   · 今日快速打卡：直接在总览页把核心项打了（小睡≤30 是自动推的，
     要改去打卡页）。哪几个按钮、什么顺序，也在 ✨ 个性化 里勾
   · 提醒：尾款超期、待办逾期、物资补货/过期
   · AI 分析（默认折叠）：整体 / 账单 / 打卡 / 物资管家 四张卡，点开才展开

💰 账单
   · 最上面就是「＋ 记一笔」+ 流水明细（日常最常用的放最前，不用再往下翻）
   · 明细默认按页显示，底部能选每页条数、也能「加载更多」；
     每行可「改」「删」；核销状态=退回 的行灰色划掉、不计入统计
   · **筛选**（2.3.5）：类别多选、关键词搜索、收/支切换、按月份 —— 找旧账不用一页页翻
   · 往下依次是：🛒 团购/核销 → 🏦 资金账户结余 → 🎁 周边尾款计划 →
     💸 尾款压力（见下文「尾款可负担性」）→ 📊 汇总（卡片+四个图）
   · 团购看板里**直接点状态就能改**（待核销 / 核销 / 退回三选一），
     不用再翻回上面的流水去改那一行；改完统计数字立即跟着变
   · 四个图：支出饼图、收入饼图、每月收支柱状图（带预算虚线）、每日支出折线
   · 「📷 从截图记账」（2.1）：把付款截图丢进去，AI 认出金额/类别/时间填进表单，
     **你核对过、点保存才写进去**，识别错了改掉就行

✅ 打卡
   · 左边日历：每格按当天核心完成度着色（绿≥80% / 黄≥50% / 灰没记），
     💭 = 那天做了梦；点格子填写那一天
   · 右边单日卡片，从上到下分区，改哪项存哪项，不用找「保存」按钮：
       🌙 睡眠   入睡/起床时间、质量1-5、夜醒、睡前手机、小睡
                 「😴 没小睡」按钮：一键把小睡记为 0，代表今天没睡午觉
       💤 梦境   先选「做梦了吗」→ 不记得=没做梦，直接完事；
                 清晰/模糊记得 → 填次数 → 每个梦一行（类型/情绪/清晰度/内容/联想）
                 → 点「保存梦境」逐条存下来（总览页那张「今日梦境」卡会显示条数）
       ✅ 核心项  大按钮点一下 √、再点 ×、再点清空（小睡≤30 自动推，不可手改）
                 **几项由你自己定**，见下文「打卡项能不能自己加」
       ➕ 加分项  同上；运动类型/时长、屏幕时长
                 「🏃 未运动」按钮：一键把运动类型标成「未运动」+ 时长记 0，
                 再点一下取消。运动是加分项，**不得分但也不扣分**
       😊 状态   心情、精力、备注
   · 小睡口径：留空＝还没记；**0＝没小睡，判为不达标（扣分）**；1~30＝达标；>30＝睡太久。
     也就是说没小睡是要扣分的，别漏点。
   · 顶部卡片 + 两张图照旧；底部梦境记录列表 = 网页录入的逐梦明细
   · 月完成率只统计「到今天为止」的日子，未来的日期不会拉低你的完成率
   · 月份自动续：到了新月份，系统启动时自动把当月铺好（列定义、公式、下拉全照旧），
     你直接填就行，不用手动建表
   · **断月自动回填**：寒暑假整月没开电脑也不会留窟窿 —— 启动后系统在后台把
     中间缺的月份补上（一次最多补 24 个月，两年），补完会提示你一声

📦 物资
   · 顶部三张卡片：药品/日用品/零食 的 总数 / 过期 / 临期 / 待补货 + 橙色提醒条
   · 「＋ 新增一条」：展开小表单，名称+常用字段一次填好保存（药品可填效期/数量，
     日用品可填类别/数量，零食可填生产日期/保质期）
   · 表格里点格子就能改，回车保存
   · 零食：「有效期(直接填)」列 —— 包装上只有到期日（如 2026-11-20）、
     没有「生产日期+保质期」的，直接把这列填了就行，它优先于推算；
     清空则回落到「生产日期 + 保质期」自动算。两种填法任选其一即可。
   · 零食专属：「🍽 吃掉1个」数量-1，吃到 0 自动标已食用并整行划掉置灰；
     「划掉/恢复」可整条标记（比如直接送人/吃光）
   · **开封日期 / 开封后(月)**：三张表都有。很多药和吃的，
     包装上印的是「没开封」的保质期 —— 眼药水开封一个月就不该再用了，
     哪怕瓶子上写着 2028 年。填上这两格，「开封后到期」会取
     「包装到期日」和「开封日期 + N 个月」里**先到的那个**。
     不知道能放多久，点每行右边「🤖 开封后多久」问 AI，
     它只给建议值填进输入框，你看过、点了保存才生效。
   · 药品行右侧「🤖 AI」：让 DeepSeek 生成「针对疾病 / 使用方法 / 大致功效 / 副作用」，
     生成后**先弹窗给你核对、可逐项修改**，点保存才落盘。
     没配 API Key 时会提示去设置页配。
   · 剩余天数 / 效期状态 / 补货状态 / 开封后到期 由系统自己算，网页只读显示 ——
     **存的是原料（日期、数量），不是结论**，所以它不会过期变假

📋 待办（2.2 起从物资页独立出来）
   · 添加（事项 / 类别 / 优先级 / 截止日期 / 备注）、✔完成、改、删
   · 逾期和快到期的会标红；总览页有一张「待办未完成」卡
   · **加到电脑日历**（2.4.5）：每条右边有个日历图标，点一下生成一个日历文件，
     双击用系统日历打开就导进去了 —— **当天和前一天各提醒一次**。
     没填截止日期的会先问你哪天。只有**还没完成**的才能导。
     导出的文件在数据目录的 `_导出\日历\` 里，随时能再导一遍
   · 日报里点「提取待办」，AI 挑出还没做完的事，你勾选、改完、确认才写进来

📔 日记（存在数据目录的 `笔记\` 里）
   · 左边选类型（日报 / 周报 / 月报）和篇目，右边写；「分栏 / 纯编辑 / 纯预览」三态切换
   · 停手 1.5 秒自动保存，也可以 Ctrl+S 或点「保存」
   · 为什么存成 Markdown 文件、不塞进数据库：日记是**长文本**，塞进表里既不好查
     也不好改。存成文件还有个好处 —— 记事本、VS Code 都能直接打开改，
     哪天不想用这个程序了，那些 .md 照样在、照样读得懂（数据不被程序绑住）
   · 文件名就是日期：日报 2026-09-15.md、周报 2026-W38.md（ISO 周）、月报 2026-09.md
   · 日报：随手记一句，AI 会把「已有内容 + 新记录」揉成一篇通顺的日记。
     AI 挂了或没配 Key 就退回原文追加，**一个字都不会丢**
   · **日报会自动带上当天的数据**：睡眠时长、核心打卡完成度、运动、心情精力、
     当天花了多少钱、记了几个梦。所以它不是纯手写，是有数据支撑的
   · 周报：读那一周（周一~周日）**所有有内容的**日报，AI 汇总
   · 月报：读那个自然月**覆盖到的**所有周报，AI 汇总（跨月周会同时进相邻两个月）
   · **已有内容永远不会被自动覆盖**。想重写要点「重新生成」并确认
   · **启动时自动补齐**：开机后系统在后台把「已结束但还空着」的周报月报补上，
     不会挡着你开窗口（后端 0.2 秒就绪，补齐在后台慢慢跑）。
     不想让它自动花钱的话，用设置页把 API Key 清掉即可（那就只做本地记录）
   · 「提取待办」：AI 从这篇日报里挑出**还没做完**的事，弹窗列出来给你勾选、
     可以就地改类别/优先级/截止日期，**确认后**才写进「待办」页。不确认不写
   · 「AI 重新整理」：把当前内容重排一遍，不新增事实（会先问你）
   · 「插图」：日记里能贴图（图存在 `笔记\_附件\`，跟着笔记一起搬）
   · 「导出」：导成 Word / Markdown / HTML 三种任选

✍ 随笔（2.3.6 新增）
   · 上面两个切换：**随笔** 和 **摘抄**
   · 随笔：想到什么写什么，跟日记同一个目录但两个文件不混。
     按**时刻**命名，一天写好几篇也不会互相覆盖
   · 摘抄：一句话 + 出处 + 标签 + 「我为什么记它」，能按标签筛
   · 两样都能插图、都能导出成 Word / Markdown / HTML

🔮 回忆书
   · 直接问关于你过去记录的问题，它会自己去翻日报、周报、月报
   · 也能查打卡和账单的数字，比如「上个月花了多少，主要花在哪」
   · **结果按相关度排**（不是按日期）：命中次数多、写在标题里的排前面。
     以前搜「学习」时最新那篇永远第一，哪怕只是顺带提一句
   · 关键词在文中出现两处、又隔得远时，会**同时给出两段**，不再只给第一处
   · 每次回答下面有「查了 N 次记录」，展开能看到它调用了哪些工具、参数是什么、
     命中几条 —— 过程完全透明
   · **没有配 API Key 时照样能用**：退回本地关键词检索，把命中的原文摆给你看，
     只是没有 AI 归纳
   · **对话会存下来**（2.4.1）：左边一列是历史会话，像微信那样 ——
     可以开好几个话题分别聊、随时切回去接着问、也能删掉某一串。
     关掉程序再打开，以前的问答还在
   · 「开启新对话」开一个新的，不会清掉旧的。**对话不会写回任何笔记**，
     你的记录只在你手改时变
   · 问答模型可以在设置页单独选（比如整理用便宜的 flash、问答用强的 pro）

━━━ 设置页 ━━━
九个分区，左边点着切。下面这些**点一下就存**，不用找保存按钮。

🎨 外观
   · 主题：浅色 / 深色 / 跟随系统
   · 配色七套，点一下就换（深浅两个版本都有）：
     古风三套 —— 米黄（默认，取自图标那套暖色）/ 青瓷 / 墨色
     柔和四套 —— 樱粉 / 蓝粉 / 藕荷 / 奶茶
   · 字体、字号、界面动画开关
   · **背景图**：选一张自己的照片当底。图片会自动缩到 1600px 存在
     `_配置\背景\` 里，不上传任何地方。三个滑块：
     **衬底 / 压暗**（浅色下叫衬底、深色下叫压暗 —— 它压的是主题底色，
     深色下把照片压暗、浅色下给照片垫一层浅底，都是为了把字衬出来）、
     **模糊**（照片太花时用）、
     **卡片通透**（卡片能透出多少照片，0~85%）。
     卡片是**实心纸面**，照片从卡片之间的缝隙和留白里露出来 ——
     2.3.7 起不用毛玻璃了：在照片上那永远是一片糊，调多少都是雾蒙蒙的
   · 图表颜色跟着主题走，换配色时四张图会一起重画

✨ 个性化
   · 「AI 怎么称呼你」：填了之后，**回忆书**和**总览页 AI 分析**会这么称呼你。
     日报周报月报是拿第一人称写的，不塞称呼进去（会很怪）
   · AI 写日记的详略三档：从简 / 适中 / 舒展。只影响写得详略，
     **不影响事实口径** —— 三档都不许编造
   · 总览页卡片：勾选管显示哪几张，↑↓（或直接拖）管谁排前面。
     一张都不勾会退回「全显示」（一张卡都没有的总览页没意义）
   · 快速打卡按钮：总览页「今日快速打卡」里出现哪几个按钮、什么顺序，
     也是同一套勾选 + ↑↓。勾掉只是不显示，**记过的数据一条不少**
   · 打卡项改名 / 隐藏：见下方「打卡项能不能自己加」的说明

📇 应急
   · 一张**应急信息卡**：基本信息、医疗警示（过敏/血型/慢性病）、紧急联系人、
     常用电话、就医与其他。分五个小块，每块能自己加行

━━━ 笔记加密（可选，默认关） ━━━
   · 位置：设置页 → 🔒 隐私 → 笔记加密。**必须先设访问密码**（密钥由它派生）
   · 算法 AES-256-GCM，密钥由密码经 PBKDF2 派生 20 万次。
     **密码和密钥都不落盘**，密钥只活在内存里 —— 所以每次重开程序都要重新解锁
   · 加密后 笔记\ 里的 .md 用记事本打开是乱码。`_自动备份` 里的笔记副本、
     回收站里的日记也一并是密文，不会从别处漏出去
   · **只加密笔记**，账目/打卡/物资这些数字不加密（它们在一整个数据库文件里，
     加密它就得先把整个程序改一遍，收益不划算）
   · 改密码会自动把所有笔记用新密钥重新加密一遍，不会把你锁在门外
   · ⚠ 代价说在前面：**密码忘了 = 笔记永久打不开**，没有后门。
     所以要么把密码记牢，要么先「关」掉加密再用（关掉就变回明文）
   · ⚠ 它挡的是「别人翻到你的文件夹」。挡不住已经拿到你电脑的人
     （内存里的密钥、键盘记录、休眠文件都能拿到）。
     真正的保护仍然是 **BitLocker 全盘加密 + 系统登录密码**

━━━ 打卡项能不能自己加 ━━━
   2.2 起**能了** —— 在 ⚙ 设置 → 个性化 → 打卡项。

   以前不行：打卡数据住在 Excel 月表里，每一项固定占一列，旁边的公式
   （睡眠时长看 AK 列、统计看板一串 COUNTIF）全按列号引用，
   插一列会让它们在 Excel 里**静默算错** —— 数字看着有，其实全偏了。

   2.0 把数据换进数据库之后这个限制就没有了：「一项」就是一组行，
   增删都不影响别人。现在可以：
     · 改名字、换类型（打勾 / 数字 / 时间 / 下拉 / 文本）、换分组
     · 新增自己的项（自动分配列号）、删除自己加的项、上下调顺序
     · 内置的十来个项**只能隐藏不能删** —— 删了已经记过的数据就没地方放了
     · 分三组：核心（计入完成率）/ 加分 / 其它（只在单日页显示）
   改完单日页和总览页的快速打卡会自动跟着变，不用管列号。
   底部「还原默认」一键回到出厂那几项。

━━━ 数据会不会自己刷新 ━━━
   · **自己记的东西会立刻反映到别的页**：在账单记一笔，切到总览，结余就是新的；
     在总览打勾，上面那排数字立刻跟着变（不用切走再切回）
   · **切过的页直接用缓存，秒开**；只有「这期间有改动」的页才会重新拉一次
   · **别处改了数据会提示你**：比如同时开了两个窗口、或者这两台设备指向了同一个
     数据目录，程序每隔几秒对一次「数据戳」，发现变过就在顶部出一条黄条：
       ⚠ 账单在别处被改过，这儿显示的还是旧的　[重新加载] [知道了]
     **它不会自动重新加载** —— 你可能正填着表，自动刷会把没提交的内容冲掉，
     数据看着新了、你刚写的却没了，那比显示旧数据更糟。点「重新加载」才真的刷
   · 一条已知的例外：AI 分析结果是缓存的，不会自己重跑（重跑要花钱）

━━━ 学期切换 ━━━
   · **一个学期一份账**：大二上、大二下各是独立的一份，流水互不干扰，
     切学期不会把两个学期混在一起算
   · 顶栏右侧的下拉可以随时切换学期；**切换只是换"现在看哪一份"，不动任何数据**
   · 设置页「📚 学期管理」能看各学期的记录条数、新建学期
   · 「新建学期」= 拿当前学期当模板，**清空流水和尾款，但保留类别、预算和格式**，
     开学不用从零配
   · 学期名不能含 \ / : * ? " < > | 这些字符

━━━ 尾款可负担性 ━━━
   · 尾款区顶部有一张「💸 尾款压力」表：未来几个月各要付多少、按你近期水平估的结余、
     付完还剩多少；某个会变负就标红提醒
   · 「预估结余」用的是**真实收入**（会把「结余」这类期初余额排除掉），
     数据不足 2 个月时会提示参考意义有限
   · 可动用资金卡片下面会写「全部尾款付清后还剩 X」——负数说明付完就不够了
   · 付尾款点 **「💰 付清并记账」**：一次完成「标为已付 + 在记录里记一笔支出」，
     两步在**同一个事务**里，要么都成、要么都不做，不会出现
     「尾款标了已付、账上却没这笔钱」。要改实际付款金额或账户，
     在弹出的窗口里改即可
   · 已经在别处记过账的，用「只标已付」只改状态

━━━ 数据安全 ━━━
   · **数据住在一个文件里**：数据目录下的 `小煦拾简.db`。账目、打卡、物资、待办、
     应急信息全在里面；日记和随笔是 `笔记\` 里的 .md 文件（见上文「日记」）
   · 每次保存走数据库自己的事务，**要么整笔写进去、要么当没发生**，
     不会出现「改了一半」的中间状态
   · **自动备份**：每天第一次改动时，自动把数据库备份一份到
     `_自动备份\`（文件名带日期）。默认保留最近 7 份，多少份能改。
     备份放哪、留几份都在设置页「💾 数据」里调；改到别的盘之后，
     老备份还在老地方，列表里仍然看得见（会标出它在哪个目录）
   · **笔记可以加密**：见上文「笔记加密」一节。开了之后文件夹里的 .md 是乱码
   · **数据目录里的 `_配置\` 别删**：里面放着 API Key、当前学期、Token 用量、
     自定义背景图、AI 分析缓存。放在数据目录而不是程序目录，
     是为了换程序版本（升级/重装）时配置不丢
   · **设置页「💾 数据备份」**：能看到所有备份（时间/属于哪个数据/大小），
     点「恢复」即可回到那一版；「立即备份」可随时手动存一份。
     **改大事之前先点一下「立即备份」**
   · 恢复是覆盖操作，所以**系统会先把当前状态自动另存一份**（列表里标「恢复前存档」），
     恢复错了还能再退回来
   · **想用 Excel 看**：设置页有「导出 Excel」，会把库里的数据导成三本表，
     放在数据目录的 `_导出\` 里。**导出是单向的** —— 你改了导出的那份，
     程序不会读它。要改数据还是在程序里改
   · **设置页「🗑 回收站」**：删掉的流水、尾款、待办、日记会先放进这里，随时能捡回来。
     最多留 300 条 / 90 天（先到为准）。
     恢复流水和尾款时**行号会变**（补到当前最后一行），金额日期类别都不变；
     日记如果已经重新写过了，恢复会被拒绝 —— 不会覆盖你后来写的。
     删除时如果回收站写不进去（比如磁盘满了），系统会**中止这次删除**，不会让你不知不觉丢掉东西
   · 数据目录里还躺着两个早期的空白表生成脚本（`每日打卡表_生成脚本.py` /
     `寝室部分物资清单_生成脚本.py`）。2.0 换了存储之后它们基本用不上了，
     留着只是备查；它们有防误覆盖保护，目标文件已存在时拒绝运行，
     确实要重建才用 `python 脚本.py --force`

━━━ AI 设置（DeepSeek） ━━━
   · 「⚙ 设置」页：填 API Key（存在 `个人信息统计\_配置\` 里，不上传任何地方）、
     选模型、改 Base URL、测试连接
   · **模型名官方改过多次**：deepseek-chat / deepseek-reasoner 已于 2026-07-24 停用，
     现在用 **deepseek-flash**（便宜快）和 **deepseek-v4-pro**（更强更贵）。
     旧的配置会自动迁移；万一又改名了，点「🔄 刷新模型列表」直接从 API 拉当前可用的。
   · **Token 用量**：设置页显示累计 tokens 与**估算花费**（按官方峰谷价目，
     高峰 = 周一至周五 9:00-12:00、14:00-18:00，其余时段半价），可分用途/模型查看
   · 用途一：药品行点「🤖 AI」生成参考信息，**先预览、可改，确认后才保存**
   · 用途二：**总览页的 AI 分析**（整体 / 账单 / 打卡 / 物资管家 四张卡）。
     每周自动更新一次；当天想看就点卡片上的「生成」或右上角「重新分析全部」
   · 用途三：**输入名称自动补全**。物资/待办/账单备注的输入框，打几个字会先从你
     已有的记录里匹配（即时、免费）；一个都没匹配上才自动请 AI 猜（约 600ms 后）
   · 用途四：**日记**（随手记整理、周报月报生成、提取待办），token 记在 `report` / `todo` 下
   · 用途五：**回忆书**问答，token 记在 `memory` 下。一次提问通常要 2~4 轮 API
     （先调工具查、再组织回答），比上面几个用途贵一些，用量面板里能单独看到
   · 用途六：**估「开封后能用多久」**（物资页每行右边那个按钮），token 记在 `shelf` 下
   · **个人基本情况**（2.2 新增）：设置页 AI 区里可以写几行关于自己的事 ——
     作息习惯、身体状况、这学期在忙什么。写完之后，上面「用途二」的四张分析卡
     和回忆书问答都会带上它，结论才贴你的实际，不像模板话。留空就完全不带。
     旁边那个开关「分析时也参考最近 3 天的日记」**默认是关的**：
     日记是最私密的东西，该由你自己决定要不要发出去。打开后也只取最近 3 天的日报
   · 调用时只把**药名 / 汇总数字 / 你自己填的那段基本情况**发给 DeepSeek，
     不含你的其他数据；日记只有在你亲手打开那个开关之后才会发
   · ⚠ AI 生成的是参考资料，不能替代说明书或医嘱，请核对后再用

━━━ 账单类别管理（在设置页） ━━━
   · 「🏷 账单类别」可以**重命名 / 上下调序 / 新增 / 删除**支出与收入类别
   · 按学期分开管：切换学期，看到的是那个学期的类别表
   · **改名和删除会把历史记录一起迁移**（删掉的归入「其他」/「其他收入」），
     保存前自动备份；「其他」「其他收入」是兜底类别，不允许删改
   · 删掉一个类别不等于删掉那些账 —— 那些流水会挂到「其他」上，金额日期都还在

━━━ 性能 ━━━
   · 2.0 把数据从 Excel 换进数据库之后，「等一下」的感觉基本没有了。
     2026-09-18 在本机实测（约 100 条流水的数据量）：
       打开一整个页面      2~4 毫秒（账单 4.4 / 打卡 3.2 / 物资 2.5）
       记一笔账           约 16 毫秒
       改一个格子         约 30 毫秒（打卡打勾、物资改数量）
   · 单格改动**只刷那一块**，不重画整页，连着点也不会卡
   · 作为对比，Excel 那会儿整页读取要 100~200 毫秒、整行写入 0.5~1 秒 ——
     那时候的「保存中…」转圈是真的在等

━━━ 开发自测 ━━━
   四套加起来**六百多项**，全部在隔离副本里跑，不碰真实数据。

   python _自测.py                    （193 项）
   自建 _测试副本\，对着副本跑全部读写接口，最后输出 _自测报告.txt。
   覆盖账单/打卡/物资/待办/应急信息、月表生成与断月回填、梦境、尾款付清联动、
   备份恢复、学期切换与新建学期、打卡项自定义、AI 提示词拼装、笔记加密的边界情况。

   python _自测_notes.py
   笔记存储层：日期换算、ISO 周、标题迁移、检索排序。

   python _自测_迁移.py
   Excel → 数据库的一次性迁移：逐项核对读数、核对不上就拒绝开机、
   原件另存一份、公式列不落库。

   python _升级校验.py
   拿真实库的**副本**去验打包版能不能正常起来。

   python _自测_加密.py
   笔记加密端到端：开 → 重启 → 读 → 改密码 → 重启 → 读 → 关 → 逐字比对。
   **全程在隔离副本（_加密测试根\）里跑，不碰真实笔记**，也不用先停服务器。
   覆盖的点：开加密后磁盘上不能有任何明文（含 _自动备份 里开加密前的副本）、
   重启后密钥还派不派生得出来、改密码后新旧文件读不读得出、关掉后逐字还原。
   为什么非要重启真服务器：密钥只在进程内存里、盐在设置文件里，
   「重启后还能读」是最容易坏也最致命的一环，假进程模拟不出来。

   前端回归（_test.html，三百多项）：起好 server 后开浏览器访问
     http://127.0.0.1:8765/static/_test.html

   用无头 Chrome 跑也行（**虚拟时间要开够，不然图还没画完就 dump 了**）：
     chrome --headless=new --virtual-time-budget=300000 --dump-dom \
            http://127.0.0.1:8765/static/_test.html
